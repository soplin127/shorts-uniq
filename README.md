# Shorts Uniq

Пакетная уникализация коротких вертикальных видео для TikTok и YouTube Shorts.
Работает на Windows, macOS и Linux. Есть графический интерфейс (PySide6) и CLI.

Каждый результат собирается **одним проходом ffmpeg**: кадрирование, цвет, звук,
скорость, музыка, субтитры и реклама попадают в один filtergraph, без промежуточных
перекодирований.

## Возможности

- **Уникализация** — масштаб и кроп-зум, яркость/контраст/насыщенность/гамма/оттенок,
  шум, виньетка, громкость, эквалайзер, тон, скорость, обрезка начала и конца, смена FPS,
  зеркалирование. У каждого параметра свой диапазон min–max и флажок включения.
- **Кодирование** — H.264 со случайным CRF и битрейтом AAC; аппаратные энкодеры
  NVENC / QSV / AMF / VAAPI / VideoToolbox с автоматическим откатом на libx264.
- **Метаданные** — полная очистка, новые теги (дата съёмки, название), проверка через ffprobe.
- **Музыка** — трек или случайный из папки, зацикливание, fade in/out,
  приглушение под голосом (sidechain ducking), замена оригинального звука.
- **Субтитры** — `.srt`/`.ass` рядом с видео или распознавание речи faster-whisper;
  стиль Shorts (по 1–3 слова), подсветка текущего слова, экспорт `.srt`.
- **Реклама** — вставка роликов в момент `7`, `00:07`, `35%` или `random:20%-60%`;
  оверлеи-картинки, видео с хромакеем, текстовые баннеры.
- **Очередь** — параллельные задачи, прогресс по файлу и общий с ETA, пауза/стоп,
  пропуск уже готовых, лог `uniq.log`, отчёт `report_*.csv`, сид для воспроизводимости.
- **Пресеты** в JSON, **превью** — первый файл, первые N секунд, с автооткрытием результата.

## Установка

Нужны Python 3.11+ и FFmpeg.

### Windows

```bash
winget install Gyan.FFmpeg
```

Либо скачайте full build с <https://www.gyan.dev/ffmpeg/builds/>, распакуйте и
добавьте папку `bin` в `PATH` (или укажите путь к ней в программе: «Очередь → Путь к ffmpeg»).

```bash
py -m venv .venv
```

```bash
.venv\Scripts\pip install -r requirements.txt
```

### macOS

```bash
brew install ffmpeg-full
```

Обычная формула `ffmpeg` собрана без libass и drawtext — субтитры и текстовые баннеры
с ней работать не будут. Программа сама находит `ffmpeg-full`, даже если его нет в `PATH`.

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

### Linux

```bash
sudo apt install ffmpeg
```

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

`faster-whisper` нужен только для `--subs auto`; если он не нужен, уберите строку из
`requirements.txt`. Модель скачивается при первом распознавании.

## Графический интерфейс

```bash
python app.py
```

Вкладки: **Файлы** (перетащите видео или папки, укажите папку результата) →
**Уникализация** → **Метаданные** → **Музыка** → **Субтитры** → **Реклама** → **Очередь**
(Старт / Превью / Пауза / Продолжить / Стоп). Меню «Пресет» загружает и сохраняет JSON.
Настройки и список файлов запоминаются между запусками.

## CLI

Базовый запуск — три варианта каждого видео по пресету:

```bash
python cli.py -i ./in -o ./out --variants 3 --preset presets/default.json
```

Всё сразу: музыка из папки, автосубтитры, рекламная вставка на 7-й секунде:

```bash
python cli.py -i ./in -o ./out --variants 3 --preset presets/default.json --music ./music --subs auto --ad ./ads/promo.mp4 --ad-at 7
```

Превью первого файла (первые N секунд из пресета):

```bash
python cli.py -i ./in -o ./preview --preview
```

Субтитры из одноимённых `.srt`, по два слова с подсветкой, с сохранением `.srt`:

```bash
python cli.py -i ./in -o ./out --subs file --max-words 2 --highlight --save-srt
```

Текстовый баннер поверх видео в случайный момент, NVENC, воспроизводимый сид:

```bash
python cli.py -i ./in -o ./out --ad-text "Ссылка в профиле" --ad-mode overlay --ad-at random:20%-60% --ad-position top --hwaccel nvenc --seed 42
```

Несколько вставок — флаги `--ad`/`--ad-text` повторяются, `--ad-at` задаётся по одному
на каждую или один на все:

```bash
python cli.py -i ./in -o ./out --ad ./ads/a.mp4 --ad-at 5 --ad ./ads/logo.png --ad-mode overlay --ad-at 50%
```

Полный список флагов: `python cli.py --help`. Флаги CLI переопределяют значения пресета.

### Имена файлов

Шаблон `--name-template` (по умолчанию `IMG_{random4}_{date}`) понимает токены
`{randomN}` (N цифр), `{date}`, `{time}`, `{uuid}`, `{stem}` (имя исходника),
`{variant}`, `{index}`. Недопустимые для Windows символы и имена заменяются автоматически.

### Продолжение после остановки

В папке результата хранится `.uniq_state.json`: при повторном запуске уже готовые
варианты пропускаются (`--no-skip` отключает пропуск). Незаконченные файлы пишутся
как `*.part.mp4` и не попадают в результат.

## Пресеты

`presets/default.json` — умеренные значения по умолчанию. Пресет можно сохранить из GUI
или отредактировать вручную; недопустимые значения отклоняются с понятной ошибкой.

## Тесты

```bash
python -m pytest -q
```

Тесты, которым нужен ffmpeg, пропускаются, если он не установлен; GUI-тесты работают
без экрана (`QT_QPA_PLATFORM=offscreen`).
